# Digitalbank Landing Page

Proyecto HTML/CSS de Digitalbank con los últimos cambios solicitados.

## Archivos principales

- `index.html`
- `styles.css`
- `style-guide.md`
- `images/`

## Últimos cambios aplicados

- El archivo de estilos se llama `styles.css` (sin `#`).
- El archivo de guía se llama `style-guide.md` (sin `#`).
- Los autores de los artículos utilizan etiquetas de encabezado `h6` con un tamaño visual equivalente al texto pequeño original.
- Se eliminaron las formas/manchas de fondo verde y negro detrás de los celulares de la sección principal.
- Se eliminaron los iconos de redes sociales del footer.
- Se eliminó el texto de copyright del footer.
- Se mantiene la estructura y el contenido restante de la landing page.
